### 基本概念

ISP: 互联网服务提供商。

分组交换（packet switching）：把要发送的数据切分成一个个分组（packet），每个分组带上包含目的地址的首部，独立地在网络中逐跳转发；通信前不预留任何资源，链路由所有分组按需共享。

电路交换（circuit switching）是一种在网络中传输数据的方式：通信开始前，先在源和目的之间建立一条端到端的路径，并沿途为这次通信预留好资源；通信期间这些资源由它独占，结束后才释放。

- FDM（Frequency Division Multiplexing）叫频分复用:一个物理链路可以承担多个用户的通信，复用就是把一条链路的资源分给多个用户共享。FDM 把链路可用的频率范围切成若干个互不重叠的频带，每个用户（每条连接）固定分到一个频带。
- TDM(Time Division Multiplexing) :TDM 把时间划分为固定长度的帧，每帧再分成若干时隙，每个用户固定占用每一帧中的同一个时隙；在自己的时隙内，该用户可以使用链路的全部速率。

### 网络模型

| OSI 七层   | 五层模型     |
| ---------- | ------------ |
| 应用层     | 应用层       |
| 表示层     | ↑ 并入应用层 |
| 会话层     | ↑ 并入应用层 |
| 传输层     | 传输层       |
| 网络层     | 网络层       |
| 数据链路层 | 链路层       |
| 物理层     | 物理层       |

其中五层模型对应真实的网络协议。

### 数据单元

| 层                 | 数据单元              | 例子               |
| ------------------ | --------------------- | ------------------ |
| 第 4 层 传输层     | 段（segment）/ 数据报 | TCP 段、UDP 数据报 |
| 第 3 层 网络层     | 包（packet）          | IP 包              |
| 第 2 层 数据链路层 | 帧（frame）           | 以太网帧           |
| 第 1 层 物理层     | 比特（bit）           | 线上的电/光信号    |

- 一个以太网帧的数据部分，装恰好一个 IP 包
- 一个 IP 包的数据部分，装恰好一个 TCP 段或 UDP 数据报

### 路由器

路由器内部有两张表：

- **RIB（Routing Information Base，路由表）**：由直连路由、路由协议（OSPF、BGP 等）和静态配置生成，记录"所有已知的路线"，可能同一个目的网段有好几条候选路径。它更新慢，不直接用于转发。大部分路由器有默认路由，少数核心路由器没有默认路由，而是记录汇总网段的路由，不用记录每一个ip。
- **FIB（Forwarding Information Base，转发表）**：从 RIB 中挑出每个网段的最优路线，再整理成适合快速查找的格式。每个包都要查它。

控制平面

- 控制平面负责决定路怎么走：根据自身接口配置的网段生成直连路由，读取管理员的静态配置，并与相邻路由器交换路由信息，计算去往每个网段应交给哪个下一跳。这类工作不常发生，但逻辑复杂（如运行最短路径算法）。RIB路由表属于控制平面。

数据平面

- 每次到达一个包，路由器就要依据目的IP查FIB表，然后从匹配目的IP的不同长度的前缀中选择最长前缀，得到出接口和下一跳，改写帧头中的两个MAC地址(每一跳经过的不同的二层网络都需要改写帧)，IP头中的TTL减1，然后从对应出接口发出。它极其频繁，逻辑简单。FIB表属于数据平面。

### 包延迟

- nodal processing: 检查比特错误，读取包头，确定出接口
- queuing delay: 在出接口的缓冲区中等待链路空闲
- transmission delay: 传输时延是把一个包的所有比特推送到链路上所需的时间
- propagation delay: 一个比特从链路一端传播到另一端所需的时间
